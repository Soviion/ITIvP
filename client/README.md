# Клиент: записи на приём (лабораторная работа №4)

React 19 + Vite 8. Приложение автономно: данные хранятся в `localStorage` браузера, серверный API не используется.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
npm run lint
```

## Что реализовано

- список записей на приём: добавление, редактирование, удаление, смена статуса;
- фильтр по статусу, поиск, сортировка (настройки фильтра и сортировки сохраняются);
- статистика, заголовок страницы с числом записей, горячие клавиши Enter и Esc;
- загрузка при старте с имитацией запроса (1 с), автосохранение с debounce 500 мс;
- работа с `localStorage` вынесена в `utils/storage.js` и хук `hooks/useLocalStorage.js`.

Ключ с записями: `clinic.appointments`. Если ключа нет, подставляются демонстрационные данные.
