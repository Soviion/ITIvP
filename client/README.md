# Клиент «Регистратура клиники» (лабораторная работа №5)

React 19 + Vite 8. Клиент работает с собственным REST API из лабораторных работ 1–3 (папка выше) через **axios**.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
npm run lint
```

Перед запуском клиента должен работать сервер (`npm run dev` в корне репозитория, порт 3000).

## Настройка (`.env`)

| Переменная | Назначение |
| --- | --- |
| `VITE_API_URL` | адрес API, по умолчанию `http://localhost:3000` |
| `VITE_API_DELAY_MS` | необязательная искусственная задержка каждого запроса (мс). Например `1500` — чтобы на защите было видно спиннер и оптимистичное обновление. `0` — выключено |

После изменения `.env` dev-сервер Vite нужно перезапустить.

## Где что лежит

| Файл | Что делает |
| --- | --- |
| `src/api.js` | экземпляр axios, интерцепторы (JWT в заголовке, **retry до 3 попыток**, обработка 401), функции CRUD записей и справочников |
| `src/authApi.js` | запросы входа, регистрации, 2FA, смены пароля |
| `src/hooks/useAppointments.js` | загрузка списка и **оптимистичные** добавление, изменение, удаление с откатом |
| `src/pages/AppointmentsPage.jsx` | главный компонент: спиннер, ошибка + «Повторить», список, форма |
| `src/auth/AuthContext.jsx` | хранение сессии (JWT в `localStorage`), вход и выход |
| `src/pages/LoginPage.jsx`, `RegisterPage.jsx` | вход (в том числе шаг с кодом Google Authenticator) и регистрация |
| `src/pages/SecurityPage.jsx`, `src/components/TwoFactor*Modal.jsx` | настройка двухфакторной защиты (QR-код, ввод кода), смена пароля |

## Как устроен retry

Запрос, который не дошёл до сервера (сервер выключен, обрыв сети, таймаут) или завершился ответом 5xx, `api.js` отправляет повторно:
всего до **3 попыток**, пауза растёт: 1 с, затем 2 с. Пока идёт повтор, под шапкой показывается полоса «Нет ответа от сервера — попытка 2 из 3».
Ответы 4xx (неверный пароль, ошибка валидации, конфликт времени) не повторяются — от повтора они не исправятся.

Чтобы увидеть это самому: откройте список записей, остановите сервер и нажмите «Новая запись» → «Создать запись».
